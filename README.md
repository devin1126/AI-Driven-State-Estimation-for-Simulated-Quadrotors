# AI-Driven-State-Estimation-for-Simulated-Quadrotors
This repository contains the implementation details and experimental results from the Physics-Informed Attentive Neural Process (PI-AttNP), Attentive Neural Process (AttNP), Deep Kalman Filter (DeepKF), Unscented Kalman Filter (UKF), and LSTM-based Physics-Informed Neural Network (PINN-LSTM) models utilized in a state estimation task for a simulated 6-DOF quadrotor. Note that the implementation for our main contribution is located in ```QuadrotorPIAttNP.ipynb```. Additionally, the implementations for DeepKF and the UKF are both located within ```QuadrotorUKF.ipynb```. The paper that provides further detail into our novel approach (PI-AttNP) and other baselines is titled [Hybrid State Estimation of Uncertain Nonlinear Dynamics Using Neural Processes](https://arxiv.org/abs/2509.12522).
